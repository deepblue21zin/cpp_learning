#  BOJ 10828 - 스택

## REQ
- 정수 저장 스택 구현, 입력으로 주어진 명령 처리
- push X: 정수 X를 스택에 넣는 연산이다.
- pop: 스택에서 가장 위에 있는 정수를 빼고, 그 수를 출력한다. 만약 스택에 들어있는 정수가 없는 경우에는 -1을 출력한다.
- size: 스택에 들어있는 정수의 개수를 출력한다.
- empty: 스택이 비어있으면 1, 아니면 0을 출력한다.
- top: 스택의 가장 위에 있는 정수를 출력한다. 만약 스택에 들어있는 정수가 없는 경우에는 -1을 출력한다.
- 입력 : 명령 수N(1~10000), N번 명령 입력

## DS
- 배열에 저장하고 저장순서대로 sort
- 각 명령 수행

## Complexity
연산별

push: 배열 1칸 쓰기 + Top 증감 → O(1)

pop: Top 체크 + 배열 1칸 읽기 + Top 증감 → O(1)

top: Top 체크 + 배열 1칸 읽기 → O(1)

empty: Top 비교 1번 → O(1)

size: Top+1 계산 → O(1)

전체

명령을 N번 처리하므로: O(N)
(입출력 포함해도 “명령 수에 비례”)
